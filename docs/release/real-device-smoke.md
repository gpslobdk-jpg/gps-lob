# SkoleGPS – test på en rigtig mobil

Brug kun et nyt, syntetisk testløb uden rigtige elevnavne eller billeder af
personer. Skriv **BESTÅET** eller **FEJLET** ved hvert punkt og noter kort, hvad
der skete ved fejl.

## Almindeligt løb

- [ ] 1. Åbn `https://www.skolegps.dk/join` på mobilen.
- [ ] 2. Indtast testløbets kode manuelt.
- [ ] 3. Gentag fra start og scan løbets QR-kode med mobilkameraet.
- [ ] 4. Indtast et opdigtet navn/holdnavn og gå videre.
- [ ] 5. Tillad GPS, og kontrollér at en frisk position vises.
- [ ] 6. Gå fysisk mod første post, og kontrollér at posten registreres.
- [ ] 7. Afgiv et almindeligt, syntetisk svar.
- [ ] 8. Tag et foto direkte med mobilkameraet uden personer i billedet.
- [ ] 9. Kontrollér på lærerens side, at fotoet kan ses.
- [ ] 10. Gå videre til næste post.
- [ ] 11. Læg browseren i baggrunden i cirka 30 sekunder.
- [ ] 12. Åbn browseren igen, og kontrollér at løbet fortsætter korrekt.
- [ ] 13. Slå kortvarigt netværket fra, og slå det til igen.
- [ ] 14. Kontrollér at forbindelsen kommer tilbage uden dobbelt svar.
- [ ] 15. Gennemfør målgang, og kontrollér resultatet.
- [ ] 16. Luk og genåbn browseren, og kontrollér den forventede slutstatus.

## Zone Krig

- [ ] 17. Start et nyt syntetisk Zone Krig-løb med rigtig GPS.
- [ ] 18. Gå fysisk ind i en testzone.
- [ ] 19. Kontrollér at zonecapture registreres én gang og på rette hold.
- [ ] 20. Test kort baggrundstilstand og kort netværksudfald igen.
- [ ] 21. Afslut løbet fra lærerens side.
- [ ] 22. Kontrollér slutstatus og resultat på både mobil og lærerside.
